Suspended (confirmed): Suspensions are created manually in Zenoti only (hub never writes Suspended). One-way sink: Zenoti Inactive → Suspended present ⇒ set GHL radio Membership Suspended → Membership Suspended; if no longer Suspended, clear it.

Form-originated cancels authoritative in GHL first, then push to Athena/Zenoti. Phone-originated cancels authoritative in Athena first, then push to Zenoti/GHL. Do not create an endless loop — hub should stamp cancel source and skip echo writes.

Zenoti Inactive reason (confirmed): Automated cancels map to Cancelled only. Suspended is manual-only in Zenoti — the hub must never write Suspended.

UX note: Membership Cancellation Data is not under Call Outcomes and must remain writable by the existing form integration. Do not apply the Call Outcomes “hide/lock” rule to these GHL fields. Athena→GHL phone-path writes should still overwrite to stay consistent.

Integration contract (proposed): Derive membership_active_athena, membership_active_zenoti, ghl_membership_cancelled, ghl_membership_cancellation_date. On Path A (GHL cancel True): set Athena Membership Status out of Active; move Zenoti membership Active→Inactive/Cancelled; preserve admin email as backup notification. On Path B (Athena leaves Active): set Zenoti Inactive/Cancelled; set GHL Membership Cancelled=True and copy cancellation date from Athena. Never auto-write Zenoti Suspended — suspensions are manual only. Admin Check List membership = yes only when Athena shows Active and Zenoti Active count includes the membership (surface Conflict if they disagree).
