Golden Record — Identity Resolution Flow

Core path for easier data entry: when any team updates a patient or lead, webhooks hit the GCP Middleware Hub. The hub matches identity, updates the master record in BigQuery, then applies the correct sync class per field — not fill-if-empty for everything. Hub sync classes (SoT: field mapping registry): fill_if_empty (eligible demographics only) · isolated_vault (payment firewall) · forced_presence_mirror (Call Outcomes set/clear) · athena_only_read · two_path_cancel (allowed Athena write) · zenoti_renewal_decline (Goal 3 Suspended + cc_zenoti=no). Fill-if-empty is not the only outbound pattern. Existing AthenaNet demographic values are never overwritten by fill_if_empty — only by an explicit product-allowed write (e.g. two_path_cancel) or a manual Athena edit. This flow remediates blanks where the class allows — it does not publish the Admin Check List. Remaining gaps, conflicts, and appointment-scoped issues are reported by the Operations reporting layer.

Bi-directional inbound — outbound by sync class Any team can be the source of a change: marketing in GHL, front desk in Zenoti, or clinical in AthenaNet. The hub resolves identity, writes the golden record once, then applies the declared sync class per field (see taxonomy). Eligible demographics use fill_if_empty; ledger attributes often use mirrors, vaults, Athena-only reads, or two-path cancel instead.

AthenaNet fill-if-empty rule: empty demographic fields are filled automatically (e.g. first name or phone entered in Zenoti writes to a blank field in Athena). Once a demographic field has data in AthenaNet, fill-if-empty never overwrites it — only a manual edit in Athena can change it.

Class isolated_vault — payment firewall: AthenaNet Card On File and Zenoti Saved Card → Payments are isolated payment instruments. The hub must not copy card tokens or “fill” Athena Card On File from Zenoti/GHL (or the reverse). Same plastic card may exist in both only via separate manual capture. Presence flags may still mirror one-way into GHL Call Outcomes per the Credit Card field map.

Class two_path_cancel — allowed Athena write: When a cancel is authoritative in GHL (online form path), the hub may update Athena Membership Status out of Active, with a stamped cancel source to prevent echo loops. Phone cancels remain Athena-authoritative and fan out to Zenoti/GHL. See the Active Membership field map. This is not fill-if-empty; it is an explicit product-allowed write.

Class zenoti_renewal_decline — Goal 3: Zenoti membership renewals charge the Zenoti Saved Card only. On payment failure (missing / expired / invalid card), ensure Zenoti membership Suspended, set GHL Membership Suspended, and force cc_zenoti=no (clear GHL Credit Card Zenoti) immediately. Leave Athena Membership Status unchanged (no auto-timer) — staff may collect a working Zenoti card within 7 business days, then manually deactivate Athena; that follow-up is ops process, not hub automation (confirmed for now; may revisit). Never charge Athena Card On File for a Zenoti renewal.

Class forced_presence_mirror: Source presence (Athena document/flag, or Zenoti Saved Card for the CC option) forces set/clear of the matching GHL Call Outcomes option. Absence clears. Not fill-if-empty; fields are integration-owned (hidden/unclickable after go-live).

Class athena_only_read: No hub outbound write. Values such as insurance eligibility, follow-up appointment, and CC agreement flags are read from Athena into BigQuery for the Admin Check List only.

Once implemented, staff enter shared demographic data in only one system — no double or triple entry for those fields. A first name or phone captured at the wellness center desk in Zenoti can flow into an empty AthenaNet record automatically. GHL and Zenoti stay in sync for missing eligible fields; AthenaNet demographics are protected once populated. Sync success still leaves a reporting need: fields that remain blank, or disagree across systems, must appear on the Admin Check List via the operations reporting layer — not assumed fixed by this map alone.
