Integration product · field mapping registry

Ledger field mapping registry

Cross-system map for Admin Check List / Record Ledger attributes: where the field lives, whether Zenoti/GHL participate, and which hub sync class applies. Fill-if-empty is only one class — not the default for every field.

Hub sync-class taxonomy

Fill-if-empty is the default for eligible demographics only — not the only outbound pattern. Every Admin Check List attribute and every hub write must declare one of these classes. Architecture pages (golden record, hub, schematic) must not invent field behavior; this registry wins. Pack reading order: Goals → field contracts → ops guarantee → how → when.

Class What the hub does Examples
fill_if_empty
Fill-if-empty demographics		 Copy master value into blank eligible demographic fields across systems. Never overwrite a populated AthenaNet demographic via this class. Name, DOB, phone, email, address/ZIP
isolated_vault
Isolated payment vault		 No token/payload copy across AthenaNet ↔ Zenoti (or via GHL). Same card may exist in both only via separate manual capture. Card On File / Saved Card
forced_presence_mirror
Forced presence mirror		 One-way set/clear of GHL Call Outcomes options from source presence (absence clears). Not fill-if-empty; integration-owned — hidden/unclickable after go-live. CC Athena|Zenoti · Pt. Picture ID · Insurance ID Front/Back · HMO Submitted?
athena_only_read
Athena-only read		 No outbound sync. Admin Check List / ops reporting reads Athena (via BigQuery) only. Eligibility · Follow-up Appt · CC Agreement flags
two_path_cancel
Two-path cancel / allowed Athena write		 Product-allowed write that may change Athena when another system is authoritative (stamped source). Not fill-if-empty. Form/phone cancel paths only. Active Membership · Paths A–B
zenoti_renewal_decline
Zenoti renewal decline (Goal 3)		 On Zenoti membership-renewal payment failure (no Saved Card, expired, or invalid/declined): ensure Zenoti membership Suspended; set GHL Membership Suspended; force cc_zenoti = no and clear GHL Credit Card Zenoti. Leaves Athena Membership Status unchanged until staff manually set inactive (confirmed for now; may revisit). Active Membership · Path D · Credit Card Zenoti
