Admin Check List — Record Ledger

Provider-scoped completeness ledger across the practice panel: each patient appears once under a single provider, with collected vs missing chart / payment / membership fields drawn from AthenaNet & Zenoti — plus Follow-up Appt after each visit.

Layout inspired by the Q3 admin workbook pattern · illustrative data only · fictitious names · not a live chart extract

Looking for the daily action / issues layout instead? See the original Admin Check List wireframe.

Design shift: The spreadsheet often lists the same patient under multiple appointment dates. This wireframe collapses to one row per patient under each provider, and turns the Yes / No / N/A columns into a ledger of what is collected vs still missing. Use Appointment Date Range to scope the ledger by Appt Date (not Follow-up Appt). Looking farther back surfaces more booked follow-ups — and flags visits that left with None scheduled.
