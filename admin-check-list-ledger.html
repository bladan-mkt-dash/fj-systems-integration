Admin Check List — Record Ledger

Provider-scoped completeness ledger across the practice panel: each patient appears once under a single provider, with collected vs missing chart / payment / membership fields. Credit Card Zenoti is operable presence — a Zenoti membership-renewal decline (Goal 3) must show CC Zenoti as No and membership not Active (Suspended) drawn from AthenaNet & Zenoti — plus Follow-up Appt after each visit.

Layout inspired by the Q3 admin workbook pattern · illustrative data only · fictitious names · not a live chart extract · shared dataset with Admin Check List rollup

Looking for the daily action / issues layout instead? See the original Admin Check List wireframe — it is a live rollup of this ledger (same patients, providers, and Appt Date filter).

Design shift: The spreadsheet often lists the same patient under multiple appointment dates. This wireframe collapses to one row per patient under each provider, and turns the Yes / No / N/A columns into a ledger of what is collected vs still missing. Use Appointment Date Range to scope the ledger by Appt Date (not Follow-up Appt). Looking farther back surfaces more booked follow-ups — and flags visits that left with None scheduled. Counts on the Admin Check List stay in sync because both pages read admin-check-data.js.
