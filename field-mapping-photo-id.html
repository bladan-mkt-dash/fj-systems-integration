Engineer rules of the road

Do not

Invent a Zenoti Photo ID field

This attribute is Athena-only for storage. Reporting and sync must treat Zenoti as N/A — not missing-because-blank.

Do not

Push the image into GHL

GHL only needs the Pt. Picture ID option checked. No DL image upload, attachment, or binary replication into Call Outcomes.

Do

Sync Athena presence → GHL option (locked)

When Athena Drivers License Image exists, select Other Important Documentation → Pt. Picture ID; when absent, clear it. After integration, hide or disable the option so staff cannot toggle it.
